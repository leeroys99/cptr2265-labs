# Lab 02 - Waterfall Project Planning
The Repair Tracker System will be developed over a 3-month period using the Waterfall model. Each phase will be completed before moving on to the next phase.

| Phase | Duration | Weeks | Description |
|---|---|---|---|
| Requirements | 2 weeks | Weeks 1-2 | Define the system features and requirements. |
| System Design | 2 weeks | Weeks 3-4 | Design the database, interface, and major system components. |
| Implementation | 4 weeks | Weeks 5-8 | Develop the Repair Tracker and its main features. |
| Testing | 3 weeks | Weeks 9-11 | Test the system, identify bugs, and make corrections. |
| Deployment | 1 week | Week 12 | Prepare and release the completed system. |
