## Goals for the Course

My goals are to learn more about software engineering practices, improve my programming skills, and become more familiar with tools used in software development.

## Reflection

I think one of the most challenging aspects of software engineering for me will be software evolution and adapting to changing requirements. When developing software, what the customer needs can change over time, and the software needs to be able to change with those needs. I believe this will be challenging because code that works well right now might become difficult to update later if it wasn't designed with future changes in mind. This is something I want to improve on because I have noticed it while working on my own projects, where adding new features sometimes required me to go back and change a lot of code I had already written.
